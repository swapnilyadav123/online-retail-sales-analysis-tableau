# 📊 Online Retail Sales Analysis using Tableau

An interactive **Tableau data analytics project** built to analyze online retail sales performance, revenue trends, customer behavior, product metrics, and country-wise business performance.

The project uses the **Online Retail dataset** and transforms transactional sales data into meaningful visual insights using Tableau.

---

## 🎯 Project Objective

The main objective of this project is to analyze online retail transactions and identify important business insights related to:

* 📈 Revenue and sales trends
* 🛒 Quantity sold
* 💰 Unit price analysis
* 👥 Customer purchasing behavior
* 🌍 Country-wise sales performance
* 📅 Monthly sales trends
* 📍 Geographic distribution of sales

The analysis can help businesses understand sales performance, identify high-performing markets, and make data-driven decisions.

## 📂 Dataset

The project is based on an **Online Retail transactional dataset** containing information about retail orders.

### Important Fields

* `InvoiceNo` – Unique invoice/order number
* `InvoiceDate` – Date and time of transaction
* `CustomerID` – Unique customer identifier
* `StockCode` – Product identifier
* `Quantity` – Number of units purchased
* `UnitPrice` – Price per unit
* `Country` – Customer country
* `Revenue` – Calculated sales/revenue value

### Revenue Calculation

Revenue was calculated using:

```text
Revenue = Quantity × Unit Price
```
